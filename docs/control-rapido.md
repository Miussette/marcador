# Operación rápida del partido

**Videos rápidos** permite añadir archivos y reproducir videos del proyecto sin salir del control. `Alt+1` a `Alt+9` reproduce los primeros nueve videos en el orden mostrado; `Alt+0` detiene el contenido. Los nombres de los botones muestran su combinación. La página Videos permite administrar los archivos.

Para acceder por teclado a cualquier botón o campo, pulsa **F8**, escribe el número de la lista y pulsa **Enter**. **Esc** cierra la lista. Incluye botones de jugadores, períodos, sustituciones, oficiales y ajustes de bocina. Los números se asignan a los controles disponibles al abrir la lista; abre nuevamente F8 cuando cambies de sección. Los campos se enfocan para editarlos con el teclado.

Atajos directos (editables en Atajos del proyecto):

| Acción | Tecla |
| --- | --- |
| Local +1 / +2 / +3 | Q / W / E |
| Visitante +1 / +2 / +3 | P / O / I |
| Restar 1 local / visitante | Ctrl+Q / Ctrl+P |
| Bocina | B |
| Reloj del partido: iniciar / pausar | Espacio |
| Descanso: iniciar / pausar, reiniciar | T, Ctrl+T |
| Descanso: 30 s / 60 s / 90 s | Ctrl+Shift+1 / 2 / 3 |
| Reloj de posesión: iniciar / pausar | S |
| Posesión: 24 s / 14 s | R / Shift+R |
| Pantalla completa | F11 |

Los atajos de partido se suspenden mientras escribes o hay un diálogo abierto. F8 permite operar los controles del diálogo. El descanso comienza en un minuto; elegir 00:30, 01:00 o 01:30 prepara esa duración detenido y Reset la recupera.

Sumar puntos en Player Stats actualiza también el resultado del equipo correspondiente. Restarlos revierte únicamente los puntos realmente descontados al jugador, sin valores negativos. Los puntos sumados directamente al equipo se conservan; no sumes dos veces la misma canasta en ambos paneles.
