# Plantilla FIBA 2

Selecciona **Diseño → Tipo: Baloncesto → Plantilla de baloncesto: FIBA 2**.

Marcador inspirado en la referencia: fondo oscuro con textura vertical, título blanco, equipos amarillos, puntuación roja, período verde, reloj blanco, tres indicadores de tiempos muertos, flechas de posesión y faltas amarillas. No incluye columnas de jugadores ni reloj de posesión.

Los datos se actualizan con el partido. El reloj muestra décimas durante el último minuto. Todos los elementos se pueden mover y editar; la plantilla se guarda automáticamente y se conserva al reabrir el editor. Restaurar recupera FIBA 2 cuando es la plantilla seleccionada.
